A brain that was never trained.

Never trained, always learning.

It learns from experience the way synapses do, one event at a time: a memory from a single glance, a value from each reward, a reflex from its own body. Plug in a trained AI model as its senses and a robot as its body, and it runs on a laptop.

It walks past 21 photographs and remembers them in order

What is different

Three ideas

Untrained

No dataset, no gradient descent, no pre-training. Every region learns online by a local rule: the hippocampus binds in one shot, the striatum follows reward-prediction errors, the cerebellum learns from its own prediction errors.

Predicted before it runs

Each behaviour follows a law written down before it was measured. Give ubrain a model's codes and it returns a certificate: how much the brain can hold with them, before anything is stored.

Any model, any body

Trained models plug in as senses (CLIP today), bodies as interfaces (a simulated humanoid, a game, a bandit). The brain sees typed channels, never pixels or motors.

Demonstration 3

It learns which action pays

Three situations, three actions each, and every action pays off with its own probability. The striatum keeps a value per situation and action and moves it toward each outcome; it chooses by a race whose runners speed up with value, so the best action wins most often but not always: it matches the payoffs, as animals do. The certificate

The prediction comes first

An episode of k items is stored in one vector, so the items interfere and recall falls as k grows. Before storing anything, ubrain.certify evaluates the law on the sense's own codes. Start

Five minutes to a learning brain

Invite-only for now. With access to the repository and uv installed, no GPU needed:

git clone https://github.com/untrained-brain/ubrain
cd ubrain
uv run examples/01_bandit.py          # the striatum learns which action pays
uv run examples/02_memory.py          # one-shot memory, against its certificate

cd bodies/mujoco && uv sync && cd ../..    # once: the G1 body
uv run --extra vision --extra video examples/g1_explorer.py --viewer

In your own code, the whole interface is one call per event:

from ubrain import Brain, Channel, Manifest, profile
body = Manifest("my-app", "v1", (Channel("situation", "event", 3),
                                 Channel("reward", "reward", 1),
                                 Channel("action", "choice", 2)))
brain = Brain(profile("player"), body)
action = brain.tick({"situation": [1, 0, 0], "reward": None})["action"]
